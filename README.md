# Wordbook App

Java(Swing)で作成するシンプルな単語帳アプリです。  
テキストファイル（JSON）を読み込んで、アプリケーションウィンドウ内に表示・編集できます。
自己学習　兼　ポートフォリオになればいいなと思い制作。

## 現在のステータス（ver 1.0)
- 基本的な機能を実装完了(2026/8/21)

## 開発環境

- 言語：Java 17
- エディタ：Eclipse
- GUI：Swing

## 現在実装した機能

- アプリ用のウィンドウを表示
- テキストファイルを読み込む
- 読み込むファイルをフォルダから選択する
- 新しい単語を登録する（既存ファイル）
- 新しい単語を登録する（新規ファイル）
- 単語帳の内容を修正する
