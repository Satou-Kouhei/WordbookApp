# Wordbook App

Java(Swing)で作成するシンプルな単語帳アプリ（になる予定）です。  
テキストファイル（JSON）を読み込んで、アプリケーションウィンドウ内に表示します。  
自己学習　兼　ポートフォリオになればいいなと思い制作中。

## 開発環境

- 言語：Java 17
- エディタ：Eclipse
- GUI：Swing

## 現在実装した機能

- アプリ用のウィンドウを表示
- テキストファイルを読み込む
- 読み込むファイルをフォルダから選択する
- 新しい単語を登録する（既存ファイル）
- 新しい単語を登録する（新規ファイル）

## 追加予定の機能

- 単語帳の内容を修正する
- 問題と解答みたいに表示する

## 安全性対策
> [!IMPORTANT]
> ** 安全性のために、以下の要素を追加する**
> 1. エラーハンドリング
> 	- refactor: catchブロックの内容を意味のある形にする
> 2. バックアップ
> 	- feature: データ書き込み時に、一時ファイル(.tmp)を作成して差し替えるようにする
> 3. バリデーションチェック
> 	- feature: ファイル拡張子と内容がword、descriptionの形になっているかチェックする
